# 📊 Tableau Dashboard – Influencer Marketing Campaign Analysis

## 📌 Project Overview
This project analyzes the performance of an influencer marketing campaign conducted by **Decathlon – Domyos (Fitness Cardio)** in collaboration with a fitness influencer.

The main objective of this project is to evaluate:
- Whether the campaign successfully **rejuvenated the target customer base (Generation Z)**
- Whether the campaign was **profitable** for the company

The analysis was developed using **Tableau**, based on transactional, customer, product, and store-level data.

---

## 🎯 Business Objectives
- Analyze customer demographics before and after the campaign
- Measure sales performance of influencer-promoted products
- Provide actionable insights to support marketing decisions

---

## 🗂 Data Model
The Tableau workbook uses a pre-prepared data source built from the following tables:

- **f_transaction_detail** – Sales transactions  
- **d_customers** – Customer demographic and loyalty information  
- **d_sku** – Product-level details  
- **d_business_unit** – Store and country information
